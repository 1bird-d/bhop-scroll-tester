# CS2 Bhop Scroll Tester

**Live: https://1bird-d.github.io/bhop-scroll-tester/**

Scroll your mouse wheel over the test box to see whether your timing suits CS2 bhops. Aim for about 16 ms per notch; faster than 15.625 ms and the game ignores the press.
All mechanics and numbers come from [zer0k-z/cs2-movement-issue-bhop](https://github.com/zer0k-z/cs2-movement-issue-bhop).
